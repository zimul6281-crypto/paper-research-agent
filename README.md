# Paper Research Agent


## 项目介绍

Paper Research Agent 是一个帮助科研人员快速理解英文论文的AI助手。

用户上传英文论文PDF后，系统自动分析论文内容，并生成结构化论文阅读卡片。


## 项目目标

解决科研人员阅读英文论文时：

- 阅读时间长
- 难以快速抓住重点
- 不容易理解论文创新点


## 当前功能

- [x] PDF上传
- [ ] PDF内容解析
- [ ] 自动生成论文卡片
- [ ] 论文问答
